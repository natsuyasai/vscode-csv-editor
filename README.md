# csv-editor

CSV ファイルをスプレッドシートのような表形式で編集できる VSCode 拡張機能です。

## インストール

- VSCode Marketplace で「csv-editor」を検索し、インストールします（Marketplace への公開後）。
- `.vsix` ファイルからインストールする場合は、次のコマンドを実行します。

  ```bash
  code --install-extension csv-editor-<version>.vsix
  ```

  `.vsix` ファイルはリポジトリで `npm run package` の後に `npx vsce package` を実行して作成できます。

動作要件: VSCode 1.99 以降

## 使い方

CSV ファイルは通常のテキストエディタで開かれます。csv-editor で開くには次のいずれかを使います。

- CSV ファイルを右クリックし、「Reopen Editor With...」から「CSV Editor」を選択する
- CSV ファイルを開いた状態で、エディタータイトルバーの「Open CSV Editor」ボタンをクリックする
- コマンドパレットで「Open CSV Editor」を実行する

いずれの方法でも、開いたファイルの内容がそのまま表形式で表示されます。

### 保存

- ツールバーの保存ボタン、または Ctrl+S（macOS は Cmd+S）で保存します。
- 編集内容は VSCode のドキュメントに反映されるため、通常の保存と同様に未保存の変更として扱われます。
- 保存時に元の CSV の書式（改行コード CRLF/LF、BOM、末尾の改行）を保持します。
- 編集は、変更した行だけを VSCode のドキュメントへ反映します（ドキュメント全体は作り直しません）。そのため、編集していない行の列数が揃っていなくても、その行は空のセルで埋められず元のまま残ります（編集した行だけが、他の行に合わせて空のセルで埋められます）。

### 読み込めない CSV の場合

列数が揃っていない、引用符が閉じていないなど CSV として解析できないファイルは、エラー内容（該当行を含む）を表示します。ファイルは変更されません。「テキストエディタで開き直す」ボタンで通常のテキストエディタで開き、内容を修正してください。

## 機能一覧

### 基本的な編集
- **セル編集**: ダブルクリック、F2、またはセルを選択して文字を入力すると編集を開始します。Enter で確定して下のセルへ移動、Escape でキャンセルします。
- **複数セル選択**: ドラッグや Shift+クリックで範囲を選択します。Ctrl+Enter（macOS は Cmd+Enter）で選択中のすべてのセルに同じ値を入力できます。
- **オートフィル**: 選択範囲の右下にあるフィルハンドルをドラッグして、連続する値を入力します。
- **セルのクリア**: Delete で内容を削除し、Backspace で内容を削除して編集を開始します。
- **行・列の追加・削除**: 行番号・列ヘッダーの右クリックメニュー、またはキーボードショートカットで操作します。
- **行・列の並び替え**: 行番号・列ヘッダーをドラッグ＆ドロップで移動します。
- **行・列のサイズ変更**: 行番号の下端、列ヘッダーの右端をドラッグしてサイズを変更します。
- **ヘッダー行の扱い**: 1 行目をヘッダーとして扱うかどうかを切り替えられます（「Ignore Header Row」）。

### データ操作
- **ソート**: 列ヘッダーをクリックして昇順・降順・解除を切り替えます。
- **フィルター**: フィルター行を表示して、列ごとに条件を入力します。ツールバーからフィルターをクリアできます。
  - ソート・フィルター中は、画面に表示されている行に対する編集が元データの該当行へ反映されます。
- **検索**: Ctrl+F で検索バーを開き、Enter / Shift+Enter または前後のボタンで一致するセルを移動します。
- **コピー・貼り付け**: 選択したセルを Ctrl+C / Ctrl+V（macOS は Cmd）でコピー・貼り付けします。改行・タブ・引用符を含む値は TSV（RFC 4180 形式）として扱われます。
- **一括編集**: ツールバーの一括編集から、選択中のセルへ値を適用できます。
- **元に戻す・やり直し**: Ctrl+Z で元に戻し、Ctrl+Y または Ctrl+Shift+Z でやり直します。

### キーボードショートカット

Windows・Linux は Ctrl、macOS は Cmd で操作します。

| 操作 | ショートカット |
| --- | --- |
| 保存 | Ctrl+S |
| 検索を開く | Ctrl+F |
| 検索を閉じる | Escape |
| 元に戻す | Ctrl+Z |
| やり直す | Ctrl+Y / Ctrl+Shift+Z |
| コピー / 貼り付け | Ctrl+C / Ctrl+V |
| 選択中のセルへ一括入力 | Ctrl+Enter |
| フィルター行の表示切り替え | Ctrl+Shift+H |
| 行・列の削除 | Ctrl+Shift+D |
| 行を上に挿入 | Ctrl+Shift+I |
| 行を下に挿入 | Ctrl+Shift+B |
| 列を左に挿入 | Ctrl+Shift+L |
| 列を右に挿入 | Ctrl+Shift+R |
| 編集の確定・下のセルへ移動 | Enter |
| 編集の開始 | F2 / Enter / 文字入力 |
| セルの内容を削除 | Delete |
| セルの内容を削除して編集開始 | Backspace |

- 行・列の操作ショートカットは、セルやヘッダーの編集中（入力欄にフォーカスがある間）は無効です。
- Ctrl+Shift+D / B / H などは VSCode 標準のショートカットと重なります。VSCode 側の動作も同時に実行される場合は、キーボードショートカット設定で VSCode 側のキーを変更してください。

### 表示・UI
- **行の高さ**: Small / Normal / Large / Extra Large から選択できます。
- **文字寄せ**: 列ごとに左・中央・右の配置を設定できます（配置モードのツールバーボタン）。
- **テーマ連動**: VSCode のライト / ダークテーマに合わせて表示が変わります。
- **大きな CSV**: 仮想スクロールにより、行数が多いファイルでも表示・編集できます。10MB 以上のファイルは、後述の「大容量 CSV（Large File Mode）」で開けます。

## 大容量 CSV（Large File Mode）

数十 MB から数百 MB（約 500 万行）の CSV を、ファイル全体をメモリに読み込まずに開く「大容量モード」です。画面に表示している範囲の行だけをファイルから読み込むため、ファイルサイズに比べて少ないメモリで動作します。

### 開き方

- 10MB 以上の CSV ファイルを csv-editor で開こうとすると、開き方を選ぶ確認が表示されます（通常モード / 大容量モード / テキストとして開く / キャンセル）。
- 50MB 以上のファイルは通常モードでは開けません。「大容量モード」か「テキストとして開く」を選びます。
- 大容量モードでは、ファイルの文字コードを選びます（UTF-8 / UTF-8 (BOM付き) / Shift_JIS / EUC-JP）。UTF-16 系には対応していません。
- 開き方は通常と同じです（「Reopen Editor With...」→「CSV Editor」、エディタータイトルの「Open CSV Editor」ボタン、コマンドパレットの「Open CSV Editor」）。エクスプローラーで CSV ファイルを開くと通常のテキストエディタで開くため、上記のいずれかの方法で csv-editor に切り替えます。ファイルの大きさに応じて、上記の確認が表示されます。
- 大容量モードで開いた画面の上部には「大容量モード（一部機能制限中）」と表示され、制限している機能の一覧を確認できます。
- 行の位置を調べている間（行インデックスの作成中）は進捗が表示されますが、作成が終わる前から先頭付近の行を閲覧できます。

### 使える機能

- **閲覧**: スクロールバーで先頭から末尾まで任意の位置へ移動できます。
- **編集**: セルの編集、ヘッダー（列名）の編集、行の挿入・削除ができます。
- **元に戻す・やり直し**: VSCode 標準の Undo / Redo に連動します。
- **保存**: Ctrl+S（macOS は Cmd+S）で、開いたときに選んだ文字コードのまま保存します。変更していない行は元のバイト列のままコピーし、変更した行だけを書き換えます。一時ファイルに書き出してから置き換えるため、保存に失敗しても元のファイルは壊れません。
- **検索**: Ctrl+F で全行を検索し、一致したセルへ移動します。
- **ソート・フィルター**: 列ごとのソート・フィルターができます。実行中は進捗が表示され、キャンセルできます。ファイル上の行順は変わりません。
- **範囲のコピー・貼り付け**: セルの範囲を選択して Ctrl+C / Ctrl+V（macOS は Cmd）でコピー・貼り付けできます。1 回に扱えるのは 10 万セルまでで、超える場合は表の上にメッセージが表示されます。
- **未保存の変更の復元**: VSCode の Hot Exit（ウィンドウを閉じても未保存の変更を残す機能）で、未保存の変更を復元できます。復元時にファイルが変更されていた場合は、変更を適用するか破棄するかを選べます。
- **外部変更の検知**: 開いているファイルが他のプログラムで書き換えられると検知します。未保存の変更がなければ自動で読み直し、あれば「再読み込み（変更を破棄）」と「変更を保持」から選べます。ファイルが削除された場合は警告を表示します（削除後は保存できません）。

### 使えない機能

- 列の挿入・削除
- 行・列のドラッグ＆ドロップによる並び替え
- オートフィル
- 列の配置（左・中央・右揃え）
- 行の高さ・列幅の変更
- ヘッダー行を無視する設定（Ignore Header Row）
- 行・列の全体選択
- 一括編集
- 検索の一致件数の表示・すべての一致の強調

この一覧は、大容量モードの画面で「制限している機能」として確認できます。Undo / Redo / 保存は、ツールバーのボタンではなく VSCode のキー操作とメニューで行います。

### 通常モードとの違い

- **ソート・フィルターはスナップショット方式**です。ソート・フィルターを実行した時点の表示順を保持するだけで、その後に編集しても並べ直しや絞り込みの再評価はしません（編集した行が条件に合わなくなっても、そのまま表示され続けます）。並べ直したいときは、もう一度ソート・フィルターを実行してください。
- **保存より前の編集は、保存後に Undo / Redo できません**。保存するとファイル上の行番号が変わるため、保存前の編集履歴は引き継げません（保存後の編集は元に戻せます）。
- **Shift_JIS / EUC-JP の保存**: 変更していない行は元のバイト列のままコピーするため、文字は変わりません。変更した行は文字コードへ変換し直します。NEC 特殊文字と IBM 拡張文字のように同じ文字が複数の符号位置に定義されている場合、変更した行の中の未編集のセルが別の符号位置（別のバイト列）で保存されることがあります（見た目の文字は同じです）。
- 全行のソートは、実行中に一時的にファイルサイズを超えるメモリ（500MB のファイルで約 1.5GB）を使います。

### 性能の目安

500MB（約 480 万行・8 列）の CSV で、一般的な Windows 環境の VSCode で計測した値です（ファイルがキャッシュに載っている状態。環境により変わります）。

| 操作 | 目安 |
| --- | --- |
| ファイルを開いてから先頭行を表示するまで | 約 0.3 秒 |
| 行インデックスの作成（全行の位置の把握） | 約 0.7 秒 |
| 任意の位置へスクロールしたときの行の取得 | 数ミリ秒（ソート後でも 100 ミリ秒未満） |
| フィルター（全行） | 約 4〜5 秒 |
| 全行のソート | 約 15〜25 秒 |
| 一致する行がない検索（全行） | 約 5〜6 秒 |
| 編集後の保存（500MB のファイルの書き直し） | 約 1.5〜2 秒 |
| 開く・スクロール・編集・保存時の拡張機能のメモリ増加 | 約 100〜200MB |

GB 級のファイルの性能は保証していません。

## 技術仕様

- **フレームワーク**: React + TypeScript（webview-ui）
- **データグリッド**: @tanstack/react-table（テーブル）+ @tanstack/react-virtual（仮想スクロール）
- **状態管理**: Zustand（一部の表示設定）
- **ドラッグ&ドロップ**: react-dnd
- **CSV 解析・出力**: csv-parse / csv-stringify
- **テスト**: Vitest + React Testing Library（webview-ui）、VSCode 拡張機能のテスト（@vscode/test-cli）、Storybook

開発手順は [webview-ui/README.md](webview-ui/README.md) を参照してください。
