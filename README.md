# csv-editor

CSV ファイルをスプレッドシートのような表形式で編集できる VSCode 拡張機能です。

## インストール

- VSCode Marketplace で「csv-editor」を検索し、インストールします（Marketplace への公開後）。
- `.vsix` ファイルからインストールする場合は、次のコマンドを実行します。

  ```bash
  code --install-extension csv-editor-<version>.vsix
  ```

  `.vsix` ファイルはリポジトリで `npm run package` の後に `npx vsce package` を実行して作成できます。

動作要件: VSCode 1.99 以降

## 使い方

CSV ファイルは通常のテキストエディタで開かれます。csv-editor で開くには次のいずれかを使います。

- CSV ファイルを右クリックし、「Reopen Editor With...」から「CSV Editor」を選択する
- CSV ファイルを開いた状態で、エディタータイトルバーの「Open CSV Editor」ボタンをクリックする
- コマンドパレットで「Open CSV Editor」を実行する

いずれの方法でも、開いたファイルの内容がそのまま表形式で表示されます。

### 保存

- ツールバーの保存ボタン、または Ctrl+S（macOS は Cmd+S）で保存します。
- 編集内容は VSCode のドキュメントに反映されるため、通常の保存と同様に未保存の変更として扱われます。
- 保存時に元の CSV の書式（改行コード CRLF/LF、BOM、末尾の改行）を保持します。

### 読み込めない CSV の場合

列数が揃っていない、引用符が閉じていないなど CSV として解析できないファイルは、エラー内容（該当行を含む）を表示します。ファイルは変更されません。「テキストエディタで開き直す」ボタンで通常のテキストエディタで開き、内容を修正してください。

## 機能一覧

### 基本的な編集
- **セル編集**: ダブルクリック、F2、またはセルを選択して文字を入力すると編集を開始します。Enter で確定して下のセルへ移動、Escape でキャンセルします。
- **複数セル選択**: ドラッグや Shift+クリックで範囲を選択します。Ctrl+Enter（macOS は Cmd+Enter）で選択中のすべてのセルに同じ値を入力できます。
- **オートフィル**: 選択範囲の右下にあるフィルハンドルをドラッグして、連続する値を入力します。
- **セルのクリア**: Delete で内容を削除し、Backspace で内容を削除して編集を開始します。
- **行・列の追加・削除**: 行番号・列ヘッダーの右クリックメニュー、またはキーボードショートカットで操作します。
- **行・列の並び替え**: 行番号・列ヘッダーをドラッグ＆ドロップで移動します。
- **行・列のサイズ変更**: 行番号の下端、列ヘッダーの右端をドラッグしてサイズを変更します。
- **ヘッダー行の扱い**: 1 行目をヘッダーとして扱うかどうかを切り替えられます（「Ignore Header Row」）。

### データ操作
- **ソート**: 列ヘッダーをクリックして昇順・降順・解除を切り替えます。
- **フィルター**: フィルター行を表示して、列ごとに条件を入力します。ツールバーからフィルターをクリアできます。
  - ソート・フィルター中は、画面に表示されている行に対する編集が元データの該当行へ反映されます。
- **検索**: Ctrl+F で検索バーを開き、Enter / Shift+Enter または前後のボタンで一致するセルを移動します。
- **コピー・貼り付け**: 選択したセルを Ctrl+C / Ctrl+V（macOS は Cmd）でコピー・貼り付けします。改行・タブ・引用符を含む値は TSV（RFC 4180 形式）として扱われます。
- **一括編集**: ツールバーの一括編集から、選択中のセルへ値を適用できます。
- **元に戻す・やり直し**: Ctrl+Z で元に戻し、Ctrl+Y または Ctrl+Shift+Z でやり直します。

### キーボードショートカット

Windows・Linux は Ctrl、macOS は Cmd で操作します。

| 操作 | ショートカット |
| --- | --- |
| 保存 | Ctrl+S |
| 検索を開く | Ctrl+F |
| 検索を閉じる | Escape |
| 元に戻す | Ctrl+Z |
| やり直す | Ctrl+Y / Ctrl+Shift+Z |
| コピー / 貼り付け | Ctrl+C / Ctrl+V |
| 選択中のセルへ一括入力 | Ctrl+Enter |
| フィルター行の表示切り替え | Ctrl+Shift+H |
| 行・列の削除 | Ctrl+Shift+D |
| 行を上に挿入 | Ctrl+Shift+I |
| 行を下に挿入 | Ctrl+Shift+B |
| 列を左に挿入 | Ctrl+Shift+L |
| 列を右に挿入 | Ctrl+Shift+R |
| 編集の確定・下のセルへ移動 | Enter |
| 編集の開始 | F2 / Enter / 文字入力 |
| セルの内容を削除 | Delete |
| セルの内容を削除して編集開始 | Backspace |

- 行・列の操作ショートカットは、セルやヘッダーの編集中（入力欄にフォーカスがある間）は無効です。
- Ctrl+Shift+D / B / H などは VSCode 標準のショートカットと重なります。VSCode 側の動作も同時に実行される場合は、キーボードショートカット設定で VSCode 側のキーを変更してください。

### 表示・UI
- **行の高さ**: Small / Normal / Large / Extra Large から選択できます。
- **文字寄せ**: 列ごとに左・中央・右の配置を設定できます（配置モードのツールバーボタン）。
- **テーマ連動**: VSCode のライト / ダークテーマに合わせて表示が変わります。
- **大きな CSV**: 仮想スクロールにより、行数が多いファイルでも表示・編集できます。

## 技術仕様

- **フレームワーク**: React + TypeScript（webview-ui）
- **データグリッド**: @tanstack/react-table（テーブル）+ @tanstack/react-virtual（仮想スクロール）
- **状態管理**: Zustand（一部の表示設定）
- **ドラッグ&ドロップ**: react-dnd
- **CSV 解析・出力**: csv-parse / csv-stringify
- **テスト**: Vitest + React Testing Library（webview-ui）、VSCode 拡張機能のテスト（@vscode/test-cli）、Storybook

開発手順は [webview-ui/README.md](webview-ui/README.md) を参照してください。
